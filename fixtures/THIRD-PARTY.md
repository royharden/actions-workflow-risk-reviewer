# Fixture provenance

All 48 workflow fixtures and labels are hand-written synthetic examples for this MIT project. They are never executed. The action names identify familiar interfaces; no upstream workflow corpus or external labels are copied. SHA-shaped values are unverified fixture data, even if one coincides with an upstream commit. `pins.json` is explicitly fixture-only.

Hand-written model examples and baseline format samples are demonstrations, not provider/scanner receipts. No hazmat corpus, GPL/AGPL/CC-BY-SA data, exploit toolkit or external taxonomy dataset is vendored. Any later third-party addition needs per-file license/provenance attribution and a separately scored split.
